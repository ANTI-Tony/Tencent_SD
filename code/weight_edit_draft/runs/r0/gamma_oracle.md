# 动态草稿长度的 oracle 上限（greedy 轨迹精确回放，256 题）

成本单位 = 一次 target 验证；r = 每个草稿 token 的起草成本 / 一次验证成本。target 单独解码 = 每 token 1。固定 γ 在 1–8 里按同一 r 选最优（相当于验证集调好的固定长度）；oracle 提前知道逐位匹配，每轮恰好起草整段匹配（上限 γmax）。加速比 = target 单独解码成本 / 该方案成本。
