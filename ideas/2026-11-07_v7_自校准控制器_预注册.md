# 预注册：自校准控制器（v7）+ 两个 kill test

日期：2026-11-07。背景：论文《When to Speculate, When to Learn》的算法贡献薄——中文场景的收益全来自开关，训练决策的价值在噪声内（8B 代码回本规则 −2.5±2.6，MoE +0.4，code+chat 混合比仅开关低 2.7%），而且式 (3) 的饱和分支在模型假设下与占空比无关（busy·T = n/r），实际是"这一批训不训"的判定。用户决定：把"去掉离线校准和运维标签的自校准控制器"作为主算法线（本文 A），并做两个便宜的 kill test（B 段长/预算、C 样本选择）。

所有运行都在同一个冻结 checkpoint 上（runs/abl/MANIFEST.json），新代码只加新文件，不改冻结文件；v7 的运行与冻结矩阵按种子配对。

## A. 自校准控制器 v7

### 假设
H-A1（无校准不掉点）：去掉每域学习曲线、每域前沿和运维标签后，v7 在 8B 代码 / 8B 中文 / MoE 代码三个场景的 B 段吞吐与 Full（v6）配对差 ≥ −2%（三次均值）。
H-A2（盈亏边界）：在 code+chat 混合上 v7 与仅开关（Switch）的配对差 ≥ −1%（v6 是 −2.7%，无标签消融变体是 −5.3%）；在 zh+chat 混合上与 Switch 噪声内（|差| ≤ 1.5%）。
H-A3（对知情调度）：v7 与 Informed 的配对差 ≥ −2.5%（8B 代码、MoE；v6 为 −1.5 / −1.2）。
H-A4（决策复现）：中文在饱和后 30 s 内关投机且训练不超过 1 轮；代码与 MoE 训到接受长度 ≥ v6 终值 −0.05；没有"结构性天花板"误判（中文不训超过 1 轮，MoE 不停训早于到顶 0.1 以内）。

### 判据
- 通过：H-A1、H-A2、H-A3 全部成立 → v7 成为论文的 Full，v6 退为"带离线校准"的消融；限制章节删掉"需要校准与标签"。
- 部分：H-A1 成立、H-A2 不成立 → v7 作为"无校准变体"进附录，正文只说一句；主方法仍是 v6。
- 失败：H-A1 不成立（任一场景 < −3%）→ 记负结果进附录，不再推进该线。
- 任何情形下都如实报告；不改判据、不加轮次挑数。

### 设计（controller_v7.py，新文件）
- 只用每目标校准：T_base(C)、T_spec(C)、Θ_plain(C)、κ(C)、训练器速率 r（冻结 model.json 的非域字段；域字段从不读取）。
- 在线前沿：Ĝ(a, C) = c · a · T_base/T_spec，c 为投机开启时"实测增益/模型增益"的 EMA（权重 0.1，截到 [0.5, 1.5]，换头后 8 s 内不更新，C < 32 不更新），切换 regime 时重置为 1。
- 学习曲线后验：a(N) = a0 + D(1 − e^{−N/N0})，(D, N0) 48×48 对数网格；先验 D ~ LogNormal(median 0.45, σ 0.8)，N0 ~ LogNormal(median 300, σ 0.9)（与域无关的弱先验，同一组常数用于所有场景）；每次换头实测增益 g（换头 8 s 后的 EMA 差）按 g ~ N(D(e^{−N1/N0} − e^{−N2/N0}), 0.04²) 更新。
- 饱和时训练判定（one-step look-ahead）：训下一轮当且仅当 E[Θ(a + E[g_next]) − Θ(a)]·max(0, H − τ) > Θ·κ·n/r；占空比取数据供给允许的最大值（≤ 0.5）。无显式停止测试：后验的期望增益自然收敛到 0。
- 天花板判定：投机当前不划算（Ĝ(a, C) < 1）且 P[a0 + D > a*(C)] < 0.25 → 不训，由开关关投机。
- 无标签 regime 检测：|短 EMA − 长 EMA| > 0.25（换头后 15 s 内不判）或饱和状态翻转（连续 5 tick）→ 重置 regime 时钟、后验、导出节奏、c，并 flush 训练缓冲。
- 其余（开关迟滞、8 s 探测、SLO 余量规则、倍增导出）与冻结控制器相同。
- 每请求 token 数：从 metrics 的 prompt/generation/request_success 计数在线估计（SGLang 适配层无这些计数时退回常数 --tpr 400）。

### 理论陈述（附录）
学习曲线边际增益非增、每轮干扰成本为常数 n/r 时，"再训一轮 iff 该轮期望净收益为正"是单调停止问题的最优规则（Chow–Robbins–Siegmund 的 monotone case）；相对知道真实曲线的知情调度，v7 多付的至多是估计误差导致的多训/少训轮次之和。只给命题与证明梗概，不做更强的 regret 界。

### 运行与预算
- 本地 mock 引擎测试（4 个脚本场景）通过后上 OSC。冒烟 2 次（m1_code、m1_zh，nB=600）。
- 矩阵：v7 × {m1_code, m1_zh, m2_code, m1_mixcc, m1_mixzc} × 3 次 = 15 次，≈ 3 GPU·h；SGLang 可选 9 次。
- 分析：analyze_cells.py 与冻结矩阵 / 混合矩阵按种子配对；干扰扫描照旧（标记即换节点重跑）。
- 预算 ≈ $1（实测 $0.138/GPU·h）。

## B. kill test：段长 × 训练预算（预实验）

问：最优训练预算是否随流量段长变化？动态选择能否稳定超过"同一开关 + 最强固定预算"？
- 场景 m1_code、m2_code、m1_mixcc；段长 nB ∈ {2000, 6000}（16000 已有）；策略 switch、fixed200（B 段起 0.5 占空比训到 200 条停）、fixed800（= Informed）、v6、v7；3 次。新增 ≈ 90 次 + 长段 fixed200/v7 各 9 次，≈ 15 GPU·h ≈ $2。
- 判据：若在某段长下 fixed200 显著优于 fixed800（配对 ≥ 3 次离散）且 v7 相对每段最强固定预算的配对差 ≥ −1%，则"预算随段长"成立，写进正文；否则写进附录作为"固定小预算够用"的结论。

## C. kill test：同预算下的样本选择（离线）

问：同样的训练 token 预算，按"预期加速收益"选样本能否学出更快的 drafter？
- 用学习曲线流水线（train_head 离线模式，3200 条）在 3 个域 × 3 次：全部样本 / 被拒绝 token 优先 / 按草稿位置加权（第 1 个草稿位出错权重最高）三种选法，预算 = 全部样本的 50%、100%。
- 判据：到盈亏线所需 token 减半，或同预算接受长度 +0.1 → 进入在线实验；否则放弃该线并记录。
- 在 A、B 之后做；需要新训练器文件（冻结 train_head.py 不改）。

## D. 强基线：Switch + 校准预算（11-08 加，来自第二份外部评价）

问：用 Full 同样的信息（标签、前沿、学习曲线），最简单的规则——前沿开关 + 每域一个离线定好的训练预算——是否已经不输 Full？
- `controller_budget.py` 策略 switch_budget：预算 = 学习曲线达到总 headroom 80% 处的请求数（chat 153、code 428、MoE code 659、mixcc 194）；曲线天花板在饱和时过不了前沿则预算 0（zh、mixzc）；每次标签切换起以 0.5 占空比训到预算为止，导出节奏与 Full 相同；无在线价值规则、无在线停止测试。
- 运行：3 单域 + 2 混合 × 3 次 = 15 次（runs/abl_budget），与冻结矩阵按种子配对。
- 现有运行已经暗示它的数字（代码 = Informed +19.7、中文 = Switch +90.9、MoE = Informed +9.3 → 最差比值 0.969 > Full 0.953），但不能拼表，要实跑。
- 判据（预先写定）：若 Switch+Budget 在三个单域场景都 ≥ Full −1%，论文承认"有校准时在线规则无额外价值"，Full(v6) 的在线价值规则退出贡献；v7 的判据加一条 H-A5：v7（无校准）与 Switch+Budget（有校准）配对差 ≥ −2%。

## 变更记录（续）
- 2026-11-08 v7.0 矩阵 14/15 跑完（m1_mixzc r3 工人预算不够未跑；m1_zh r3 被干扰扫描标记 0.841，B 段 526 s，同节点慢）。结果：H-A1 过（vs v6：代码 +0.8±1.2、中文 +0.7±6.4、MoE +1.2±0.9）、H-A3 过（vs Informed 代码 −0.7、MoE −0.05）、H-A4 过（中文 B+30 s 关投机 0 轮；代码/MoE 3 轮到 2.65/2.97）；**H-A2 不过**：code+chat 对仅开关 −2.4±0.5（三次同号），zh+chat −1.8±1.3（2 次）。
- 原因（日志）：code+chat 上前沿修正 c 的参照是校准文件里的纯解码吞吐 Θ_plain(C)，那是用对话流量量的，混合流量的实际纯解码吞吐高 ~10%，于是 c≈1.0–1.2、模型增益 1.1，投机整段开着，而实测相对关投机状态只有 0.977。这是设计缺陷：无标签控制器不能引用任何依赖流量的校准常数。
- **v7.1（改后重跑全部 15 次，v7.0 结果保留在 runs/abl_v7 作记录）**：前沿的"截距"改为 regime 内成对实测——投机开时的干净吞吐（记录当时接受长度）÷ 投机关时的干净吞吐，都在饱和、换头 8 s 外、切换 2 s 外测；没有成对测量时 c=1（纯比例模型，即 nocurve 变体的做法）。当投机开着、regime 内还没有关状态吞吐、且模型增益在 1±0.12 内时，关投机 8 s 做一次"关探测"（与换头后"开探测"对称；远离盈亏点时不探）。关状态吞吐超过 240 s 视为过期可重测。thr7 的基准改用实测关状态吞吐（饱和时）。判据 H-A1–A5 不变。
- 2026-11-08 晚 判定：**D 成立**（Switch+校准预算 vs v6：代码 +1.5±1.8、中文 +1.8±3.3、MoE +0.7±0.5 同号；vs Informed +0.03 / −0.5；混合 vs Switch −2.0 / −1.1）。**v7.1 负结果**：代码 vs v6 −1.6±3.8、vs Informed −3.1；code+chat vs Switch −6.6±1.1；zh+chat −2.4；MoE +1.4。日志根因：关探测/开关切换后接受长度的长 EMA 用切换瞬态初始化，16 s 后被判成"接受漂移"→ regime 重置 → 后验清零、导出节奏重来（mixcc 每次 2–3 次重置、7–10 次换头）；此外在盈亏点附近"关着训、换头开探测"的切换与探测代价本身就接近它能学到的 1–2%。按预注册不再出 v7.2：无校准变体以 v7.0 为准（H-A1/A3/A4 过、H-A2 不过），v7.1 作为负结果记录。c0818 节点坏掉的两次已挪开并重跑（只为记录完整）。
