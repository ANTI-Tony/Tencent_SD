# 预注册：同卡在线适配的租买（ski-rental）模型与回本等待规则（实验 E）

日期：2026-11-09。来源：两份外部评价对"ski-rental"切入点的修正（见对话）。所有运行在冻结 checkpoint 上，新文件不动冻结代码，按种子配对。

## 受限模型
一段流量时长 T 未知。固定一个训练检查点 n*（同一个头）：
- b：训练到 n* 并上线造成的直接服务损失（token）；
- Δ：n* 的头上线后每秒多服务的 token（相对不训练时的状态：投机划算就是投机，不划算就是关投机状态）；
- τ：从开训到 n* 的头生效的时间；
- 训练中累计直接损失 C(u) ∈ [0, b]，流量结束后不再有损失；一段内 b、Δ、τ 固定；只更新一次；适配不跨段复用。
相对"一开始就有 n* 的头"的参照，知道 T 的最优损失 OPT(T) = min{ΔT, b + Δτ}。

**命题**：等 regime 持续 s = b/Δ 秒后再开训（Δ ≤ 0 则不训），最坏损失 ≤ 2·OPT(T)。证明分三种情形：T ≤ s 两者都不训；s < T < s+τ 时算法损失 ΔT + C(T−s) ≤ ΔT + b ≤ 2ΔT；T ≥ s+τ 时算法 2b + Δτ ≤ 2(b + Δτ)。
**保证只针对损失的服务量；现有控制器（90–600 s 截断的剩余时长预测、在线改目标、多次换头）不被此命题覆盖，只写成受命题启发的实现。** 占空比不作为优化维度（实现里取数据供给允许的最大值）。

## 实现（controller_budget.py 的 switch_budget 策略 + WAIT 参数）
- `--budget-n n* --budget-domains <B 域> --single-export 1 --wait-mode {none,payback}`：只在 B 域训、一个头在 n* 导出；payback = regime 年龄（首次观测到流量起）≥ s 才开训。
- b、Δ 从校准冻结：Δ = Θ(n* 的头) − Θ(不训状态)，Θ 按 C=256 的前沿（增益 ≤ 1 时取关投机状态 = 0.97·纯解码）；b = Θ₀·κ(256)·n*·tpr / r。`--delta-scale` 只改控制器拿到的 Δ̂（偏差实验），不改段长。
- τ 不进入规则，只用于选段长：τ ≈ n*/到达率 + 导出换头 ≈3 s（abl_budget 实测首个头 1.4–6.7 s）。若等待期间缓冲了数据，实际 τ 会更短——记为模型与实现的差异，事后按日志报告。
- 检查点：m2_code 与 m1_code 用 n* = 3200（s = 38 / 50 s），m1_mixcc 用 1600（s = 71 s；3200 的最长段超过 16,000 条提示池）。

## 对照与段长
策略（同一到达序列、同一开关、同一 n*）：switch（不训）、train_now（一来就训）、wait（等 s）、v6（现有控制器，原样）。
段长（请求数，由到达率换算）：0.5s、s+τ/2（训到一半流量结束）、s+τ+0.5s（刚上线未回本）、s+τ+2s（已回本）：
m2_code 1000/3850/6700/9650；m1_mixcc 1250/3500/5750/9550；m1_code 1300/4400/7550/11350。
首轮 m2_code + m1_mixcc：2 × 4 × 4 × 3 = 96 次；第二轮 m1_code 48 次；第三轮偏差变体 wait_d05 / wait_d2 在 m2_code：2 × 4 × 3 = 24 次。预算约 15 GPU·h ≈ $2。

## 指标与判据
- 主指标：B 段吞吐，以及相对 switch 的净 token 增减；同时报 p99 TPOT。饱和段 SLO 内 goodput 在 MoE 为 0，只比较饱和吞吐，写明。
- 机会损失另报：参照 = 同一 n* 下的事后最优（每个段长取 train_now 与 switch 中实测更好者）；只报绝对损失，有限实验中的比值称为经验损失比，不当作最坏情况证明；最优损失接近 0 时不算比值。
- 判据（预先写定）：E1：在 0.5s 档，wait ≈ switch（|差| ≤ 1.5%）且 train_now 明显更差（≥ 3 个点）；E2：在 s+τ+2s 档，wait 与 train_now 差 ≤ 1 个点（等待只多付一个 b）；E3：s+τ/2 档验证"流量中途结束时训练被中止、已付成本计入该段"（看日志与吞吐）；E4：偏差变体：Δ̂×0.5 推迟开训、Δ̂×2 提前开训，对应档位的损失方向与模型一致。
- 结论写法：E1–E2 成立 → 论文主张"受限模型下有保证的单次更新规则 + 实机验证"；不成立 → 如实报告偏差来源（b 低估/τ 变化），不改规则再跑。
